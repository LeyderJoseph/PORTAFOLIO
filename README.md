## 🚀 Cómo Ejecutar el Proyecto

1. Clona o descarga el repositorio.
2. Asegúrate de que todas las imágenes estén en la raíz del proyecto y la carpeta `STAR WARS/` con sus respectivas imágenes.
3. Abre `index.html` directamente en tu navegador, o sirve los archivos desde un servidor local (por ejemplo con la extensión **Live Server** de VS Code).

> ⚠️ Las rutas de las imágenes usan rutas absolutas desde la raíz (`/IMAGEN CV.jpg`). Se recomienda servir el proyecto desde un servidor local para que funcionen correctamente. Evita abrirlo directamente con doble clic desde el explorador de archivos.
